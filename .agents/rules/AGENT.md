# Rules

## Frontend

- Act like a senior developer with 20 years of experience, follow always best practices.
- Follow material ui style guide by google for designs.
- Avoid using `sx` prop in mui components, extend theme instead and reuse components.
- use useQuery for data fetching from tanstack/react-query.
- Use safe types, do not use any.
- Handle small components, avoid files with more than 250 lines, split accordingly.
- Avoid using styled components, search for a material component.
